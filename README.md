# Концепты лендинга — кондитерские техкарты

Четыре дизайн-направления для сайта, который продаёт наборы технологических карт (449 ₴, оплата онлайн).

- `index.html` — оболочка с переключателем концептов (десктоп / телефон, стрелки, клавиша M)
- `dark-premium.html` — тёмный редакционный (графит + латунь)
- `swiss-catalog.html` — швейцарский технический каталог
- `retro-bakery.html` — крафтовая пекарня (ретро)
- `pastel-atelier.html` — пастельное ателье, собрано под @cakes_with_benefits

Шрифты — Google Fonts. В четвёртом концепте стоят фото из профиля Instagram как временные заглушки.
